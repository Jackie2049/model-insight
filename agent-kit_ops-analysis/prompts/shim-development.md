# kernel 等价替换通用方法论（shim 开发规程）

> 当模型依赖本机无法运行的外部 kernel（audit 的 `missing_deps` /
> `external_calls` 指出），用**纯 torch 基础算子**写一个数学等价的替换件
> （shim），让它进模型树、在图上被标记为"等价替换"。

## 1. 识别：哪些调用真的需要替换

- audit 报出的是"引用存在"，不等于"执行路径需要"：先判断该 kernel 是否在
  你要跑的 forward 路径上（看调用点所在函数是否被调用、是否有本地回退分支）；
- 不在路径上的：不替换，但把判断依据记进 notes；
- 在路径上的：进入本规程。**注意 try/except ImportError 回退分支**——
  模型可能已经带了纯 torch 回退（audit 的 `fallback_branches`），有回退时
  优先确认回退是否可用，可用则无需自写 shim。

## 2. 数学语义等价判据（核心纪律）

**等价的是数学定义，不是实现结构**：
1. 逐行读原 kernel 源码（毛坯内通常带有参考实现或调用说明），写出它的
   数学定义：输入 → 中间量 → 输出，每步的张量语义（缩放系数、轴、
   量化格式、边界处理）；
2. 用纯 torch 基础算子表达同一数学定义（linear / matmul / softmax / amax /
   cast / reshape……），**不追求代码结构相似，只追求逐元素数学等价**；
3. 数值纪律（量化/低精度类 kernel 通用）：
   - 内部计算**升到 float32**（amax、缩放、量化尺度计算）；
   - 输出**转回模型期望的 dtype**（看调用处上下文）；
   - 缩放/舍入的顺序、clamp 的边界值、eps 的位置逐一对齐源码；
   - **位级等价要求下运算式逐字复刻源码**——fp32 中 `amax/448` 与
     `amax*(1/448)` 不位级相等（乘倒数引入舍入差），对拍要求位级一致时
     除法就写除法，不要"优化"成乘法。

## 3. nn.Module 化与挂树接管（两个动作都要）

```python
class XxxShim(torch.nn.Module):
    def __init__(self, /* 数学定义需要的常量 */):
        super().__init__()
        # 只存"数学定义的一部分"的常量；不复制模型权重
    def forward(self, x, ...):
        ...  # 纯 torch 基础算子表达
```

- **挂树**：spec `shims[].mount_name`（`add_module`）→ 模型树上有名有姓，
  图上成节点（红虚线标记的锚点）；
- **接管调用**：spec `shims[].rebind`（把 shim 实例 setattr 到入口模块的
  原函数名上）或 sys_path 遮蔽（shim 目录放 sys_path 前面，提供同名模块）。
  **只挂树不接管 = 图上看不见；只接管不挂树 = 图上无名**。两个动作缺一不可。
- **模块级缓存纪律**：shim 内跨调用复用的张量（常量、查找表……）一律缓存
  **numpy 数组**，用时 `torch.from_numpy(...)` 物化——缓存张量在抓图时会
  被打上节点标记，跨 trace 泄漏标记、污染后续作业的图。

## 4. 等价性验证（每个 shim 必做，记录进 IR）

按可行性择一，并把方法与结果写进 `contract.replacements[].evidence`：
- **对拍原实现**（原 kernel 在某种环境可运行时）：小规模随机输入
  （覆盖边界：全零、极值、非对齐尺寸），比较输出
  `torch.allclose(atol/rtol 按精度合理设定)`，记录最大误差；
- **对拍数学定义**（原实现完全不可运行时）：把 §2.1 的数学定义独立写一遍
  参考式（可与 shim 实现不同结构），随机输入对拍；再补边界用例；
- **元数据验证**：shape/dtype 完全一致 + 数值分布合理（均值/方差量级、
  量化格点检查）。元数据验证只能证明"不破坏管线"，证明不了数学等价——
  如实声明验证到哪一级。

## 5. 记录格式

每个 shim 在 IR `contract.replacements[]` 一条：
```json
{"what": "被替换的 kernel 名（模块.函数）",
 "why": "为什么必须替换（缺依赖/仅 GPU/…）",
 "equiv": "数学等价说明（定义式 + 数值纪律要点）",
 "evidence": "验证方法与结果（对拍对象、误差、用例数）",
 "shim_class": "XxxShim（与 spec.shims[].class 一致，供可视化关联）"}
```

## 6. 自检

1. 每个 shim 挂树 + 接管双动作齐全（图上可见且被真实调用）；
2. 数学定义有源码行号依据（evidence 五要素同 S2a 标准）；
3. 等价性验证按 §4 执行并留痕；
4. shim 文件全部在 `outputs/<模型>/capture/shims/`，文件头注释写明
   对应的 replacements 条目。
